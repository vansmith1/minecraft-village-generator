# Minecraft Village Generator (University Group Project)
This was my assignment for Year 1 Semester 2 C++ Studio class.

## Description
This project was developed as part of a group assignment. Unfortunately, it cannot run, as it is 
dependent on my other teammates code as well.

## Project Context 
This was a group assignment between three people, to build a village generator mod that could be run in minecraft. 
There were three tasks; place waypoints, build houses on waypoints, and build paths connecting these waypoints. 
My task was to connect the waypoints.

## Algorithms used
I used a Breadth First Search algorithm for finding pathways between the waypoints. 
I used a Manhattan Distance algorithm to determine the shortest path between each waypoint.

## My Contribution
- Implemented a pathfinder (Breadth First Search)
- Implemented a plot selection algorithm.
- Implemented a manhattan distance code.
